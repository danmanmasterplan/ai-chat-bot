# ai-chat-bot

This a file with python code files that work together to create a simple chat bot that can give ordinary premade responses to simple inputs.\

It can also search the internet and give URL that have information related to what you put in and it has the ability to save presonses to put in the memory.json file.

The chat bot.py file is responsible for reading, writing, and loading resposnses into memory and formating the program's response to internet search queries.

The Internet.py file handles actually serching the internet for the user given query and finds 5 titles, body and urls related to the query. 

the main.py file houses the format instructions for the possible user inputs as well as bringing the other code files into use.

the requirements folder contains what library you would need to download in order for this code to work.
